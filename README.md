# Event Management System — MERN

A manageable MERN stack Event Management System.

## Features
- Register and login
- Browse events
- View event details
- Admin event CRUD
- Register for events
- View personal registrations
- MongoDB persistence
- JWT authentication

## Structure
- `frontend` — React + Vite

### Frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```

Open the URL shown by Vite, normally `http://localhost:5173`.

## Demo admin
Register a user, then in MongoDB change that user's `role` from `user` to `admin`. The admin dashboard will then allow event creation, editing and deletion.
